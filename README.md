# changeleader

하나증권 체인지리더 발표용 **내부 결재 집중화 인터랙티브 프로토타입**입니다.

## 핵심 동작

- 현재 접속일을 기준으로 12건의 목업 결재 데이터 날짜를 자동 생성
- 기준일도 브라우저의 현재 날짜/시간으로 자동 표시
- 신규 결재 2건은 항상 오늘자 `결재대기 + 안읽음 + NEW`로 표시
- 알림의 신규 결재 2건과 결재대기 탭의 실제 문서가 연결됨
- 문서 행을 클릭하면 하나포털 내부에 문서 탭이 열림
- 열린 문서는 자동으로 읽음 처리
- 문서를 실제로 열면 자동으로 읽음 처리되며, 사용자가 다시 안읽음으로 변경할 수 없음
- 읽음 상태는 날짜별 localStorage에 저장되어 새로고침 후에도 유지
- 결재대기 문서의 `결재하러 가기` 클릭 시 원천 시스템 SSO 전환 화면 표시
- 상태/시스템/날짜/읽음 상태 필터, 검색, 정렬, 페이지네이션 동작

## 날짜 생성 정책

임의 랜덤값이 아니라 접속일 기준 `오늘 ~ 7일 전` 오프셋을 사용합니다.

예를 들어 11월 20일에 접속하면 기준일은 11월 20일로 표시되고, 문서 요청일도 11월 20일·19일·18일… 범위로 자동 변경됩니다. 따라서 시간이 지나도 과거 월에 고정된 목업처럼 보이지 않습니다.

## 고정 건수

시스템 카드와 상태 합계는 발표 스토리와 정합성을 유지하기 위해 항상 고정합니다.

- 전체 12
- 하나포털 3
- 하나플러스 4
- 컴플라이언스시스템 2
- 정보보호포털 2
- 법령통지시스템 1
- 승인완료 4 / 결재대기 6 / 반려 2

필터를 눌렀을 때는 **하단 문서 목록만 필터링**되며 카드 숫자는 변하지 않습니다.

## 프로필 이미지

김하나 프로필은 하나 파워 온 스토어 홈페이지에 노출된 별돌이·별순이 캐릭터 이미지 중 **오른쪽 별순이 영역을 원형으로 크롭**해 사용합니다.

## 발표 단축키

- `1`: 전체 대시보드
- `2`: 결재대기
- `3`: 결재대기 + 하나플러스
- `4`: 신규 하나플러스 결재 문서 탭 열기
- `5`: 하나플러스 SSO 전환


## A안 UI 및 탭 정책

- 실제 사내 시스템처럼 상단 헤더·검색·프로필·상태 탭·카드를 압축했습니다.
- 표 본문은 13px 수준으로 유지해 데이터 가독성을 우선합니다.
- 읽음은 **회색 열린 편지**, 안읽음은 **하나 그린 닫힌 편지** 아이콘으로 표시합니다.
- 봉투 아이콘은 상태 표시 전용이며 클릭할 수 없습니다.
- 사용자가 읽음/안읽음을 수동 변경하는 기능은 두지 않습니다.
- 문서를 한 번 열면 읽음 상태가 유지됩니다.
- 업무 탭은 **결재 대시보드 + 결재 상세 1개**까지만 존재합니다.
- 다른 결재 문서를 열면 새 탭을 추가하지 않고 기존 결재 상세 탭의 내용만 교체합니다.
- 결재하러 가기는 상세 탭 안에서 SSO 화면으로 전환됩니다.
- 시스템 카드는 하나 그린 바탕 + 흰색 선형 심볼의 앱 아이콘 스타일을 사용합니다.
- 공식 하나증권 심볼은 외부 raw URL 대신 CI 자산을 data URI로 내장해 로딩 실패 가능성을 줄였습니다.
- 별순이 원본 사이트 이미지가 로딩되지 않는 환경에서는 깨진 이미지 대신 하나 그린 별 모양 fallback 아바타가 표시됩니다.


## SSO 리다이렉트 연출

결재하러 가기 클릭 후 단순 텍스트/로딩바 화면 대신 실제 시스템 이동을 연상시키는 전환 애니메이션을 사용합니다.

1. 하나포털 결재 상세 화면이 축소되며 이동을 시작
2. 데이터 패킷이 중앙 SSO 보안 게이트를 통과
3. 하나플러스 목적지 카드가 활성화
4. 목적지 카드가 화면 중심으로 확장되며 하나플러스로 전환되었음을 표시

실제 하나플러스 결재 화면 콘텐츠는 구현하지 않습니다. 이 장면의 목적은 'SSO를 거쳐 기존 결재 시스템으로 리다이렉트된다'는 흐름만 명확하게 전달하는 것입니다.


## 결재 현황 집계 애니메이션

대시보드 첫 진입과 새로고침 시 기존 시스템에서 결재 현황을 가져오는 흐름을 약 2초 동안 시각화합니다.

- 하나포털을 제외한 별도 원천 시스템 카드 5개가 순차 활성화
- 각 카드에서 하나 그린 데이터 패킷이 중앙 `결재 대시보드` 허브로 이동
- 수신 시 각 시스템 카드에 잠시 `연결됨` 상태 표시
- 모든 데이터가 모이면 `5개 시스템 · 12건 동기화 완료` 표시 후 일반 대시보드로 자연스럽게 복귀
- 필터/탭 조작 시에는 반복 재생하지 않으며 첫 진입과 새로고침에서만 실행
- `prefers-reduced-motion` 환경에서는 이동 애니메이션 없이 완료 상태만 짧게 표시

이는 실제 결재 엔진 통합이 아니라 각 기존 시스템의 결재 현황을 하나포털 대시보드에 집중화하는 구조를 시각적으로 설명하기 위한 연출입니다.
