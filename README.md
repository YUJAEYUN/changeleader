# changeleader

하나증권 체인지리더 발표용 **내부 결재 집중화 인터랙티브 프로토타입**입니다.

## 구현 목적

분산된 결재 시스템을 새로 통합 구축하는 대신, 가장 자주 사용하는 하나포털을 결재 허브로 활용하는 사용자 경험을 시연합니다.

- 하나포털: 문서 수발신
- 하나플러스: 업무 전자결재
- 컴플라이언스시스템
- 정보보호포털
- 법령통지시스템
- 문서의 `결재하러 가기`를 누르면 해당 시스템으로 SSO 이동

프리즘은 현재 사용자가 확정한 화면 시안에 포함되어 있지 않아 프로토타입에서는 제외되어 있습니다.

## 실행 / Vercel

순수 정적 HTML/CSS/JS입니다.

- Framework Preset: Other
- Build Command: 없음
- Output Directory: 없음
- 환경변수: 없음

Vercel에서 저장소를 연결하면 루트의 `index.html`이 그대로 배포됩니다.

로컬에서도 바로 실행할 수 있습니다.

```bash
python -m http.server 8000
```

## 실제 인터랙션

- 상태 탭: 전체 / 승인완료 / 결재대기 / 반려
- 시스템 카드 필터
- 문서 검색
- 상세필터(요청일)
- 요청일 정렬
- 페이지네이션
- 페이지당 5/10/20건 변경
- 새로고침
- 승인완료/반려 문서 상세 drawer
- 결재대기 문서의 `결재하러 가기`
- 대상 시스템별 SSO 전환
- 알림 / 프로필 / 상단 메뉴 / 좌측 메뉴 반응
- 발표용 키보드 단계 이동

### 발표 키

| 키 | 화면 |
|---|---|
| 1 | 전체 대시보드 |
| 2 | 결재대기 6건 |
| 3 | 결재대기 + 하나플러스 선택 |
| 4 | 하나플러스 첫 결재 이동 버튼 강조 |
| 5 | 하나플러스 SSO 전환 |

## 데이터 정합성

카드는 **전체 보유 건수**이므로 상태/시스템 필터를 눌러도 숫자가 바뀌지 않습니다.

- 전체 12건
- 하나포털 3건
- 하나플러스 4건
- 컴플라이언스시스템 2건
- 정보보호포털 2건
- 법령통지시스템 1건

상태 합계:

- 승인완료 4건
- 결재대기 6건
- 반려 2건
