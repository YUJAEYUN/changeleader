# changeleader

하나증권 체인지리더 발표용 **내부 결재 집중화 프로토타입**입니다.

## 목적

하나포털을 결재 허브로 활용해 여러 시스템의 결재 현황을 한 화면에서 확인하고, 결재 문서 선택 시 해당 원천 시스템으로 이동하는 흐름을 시연합니다.

- 하나포털: 문서 수발신
- 하나플러스: 업무 전자결재
- 컴플라이언스시스템
- 정보보호포털
- 법령통지시스템
- 시스템 간 이동은 SSO(통합인증) 연동을 전제로 표현

> 프로토타입은 신규 결재 엔진을 만드는 것이 아니라, 하나포털에서 결재를 모아 보고 기존 시스템으로 연결하는 허브 경험을 보여주는 데 초점을 둡니다.

## 실행

별도 설치나 빌드가 필요 없습니다.

1. 저장소를 내려받습니다.
2. `index.html`을 브라우저로 엽니다.

로컬 정적 서버를 쓰고 싶다면:

```bash
python -m http.server 8000
```

그 다음 `http://localhost:8000`으로 접속합니다.

## 시연 흐름

화면 클릭으로도 동작하고, 발표 중에는 숫자 키로 즉시 단계 이동이 가능합니다.

| 키 | 단계 |
|---|---|
| 1 | 전체 결재 대시보드 |
| 2 | 결재대기 6건 필터링 |
| 3 | 하나플러스 선택 → 결재대기 2건 |
| 4 | 첫 번째 `결재하러 가기` 버튼 강조 |
| 5 | 하나플러스 SSO 이동 화면 |

`Esc` 키를 누르면 SSO 화면에서 하나플러스 결재대기 목록으로 돌아옵니다.

## 고정 데이터

발표 시 숫자가 흔들리지 않도록 카드 수치는 항상 다음 기준을 유지합니다.

- 전체 12건
- 하나포털 3건
- 하나플러스 4건
- 컴플라이언스시스템 2건
- 정보보호포털 2건
- 법령통지시스템 1건
- 승인완료 4건 / 결재대기 6건 / 반려 2건

상태/시스템 선택은 **아래 문서 목록만 필터링**하고 시스템 카드의 전체 건수는 바꾸지 않습니다.

## 디자인 기준

`hana_securities_ppt_design` 저장소의 승인 운영 브랜드 프로필을 참고했습니다.

- Deep teal: `#006060`
- Primary green: `#009070`
- Pale mint: `#C0E0E0`
- Alert red: `#E02020`
- 서체: 하나2.0 우선, 미설치 환경에서는 시스템 한글 산세리프 fallback

검색, 긴급 결재, 우선순위 등 제안 범위에 없는 기능은 포함하지 않았습니다.
